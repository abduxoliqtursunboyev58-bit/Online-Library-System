Online Library System

Advanced Programming Project | Student ID: 100004990

Project Overview

This project is a comprehensive desktop application designed to manage library inventories. Built using Python, it implements a robust Client-Server architecture. The system features a Flask (REST API) backend that handles data persistence via JSON, and a user-friendly Tkinter frontend for managing books, films, and magazines.
